# Title: Hierarchical Functional Organization and Cross-Class Bridges in Evo2 Embedding Space
# Experiment description: Load cached embeddings (run_0/data/embeddings_evo2_7b.npy) and dataset (run_0/data/dataset.json). (1) Annotate sub-pathways: for each DNA repair gene symbol in the cached dataset, determine which original KEGG pathway(s) it came from by re-querying the pathway lists (hsa03430=MMR, hsa03420=NER, hsa03440=HR, hsa03410=BER); tag each gene with sub-pathway label. (2) Identify bridge genes: find gene symbols that appear in both DNA repair and TSG lists (e.g., BRCA1, BRCA2, MLH1, MSH2, MSH6, PMS2). (3) Hierarchical clustering: perform Ward linkage clustering on embeddings, compute cophenetic correlation, generate dendrogram colored by class and sub-pathway. (4) Sub-pathway coherence: for each DNA repair sub-pathway with ≥3 genes, compute mean pairwise cosine distance within sub-pathway vs between different sub-pathways (within DNA repair class). Compare to null distribution from 1000 permutations of sub-pathway labels. (5) Bridge gene analysis: compute mean cosine distance from each bridge gene to DNA repair centroid vs TSG centroid; test if bridge genes are significantly closer to DNA repair centroid than other TSGs (t-test). (6) Visualize: UMAP colored by sub-pathway, dendrogram, and distance distribution plots. Report all metrics with p-values.
