# Title: Hybrid SVD-Neural Network Correction Framework
# Experiment description: Develop cascade system: SVD coarse correction followed by NN residual optimization. Compare pure NN/SVD against hybrid approach in computational cost and orbit minimization. First, a coarse correction is done with SVD. Then, a neural network is applied to correct the residual orbit. The model for neural network was trained specifically on residual orbits after SVD correction, with clipped corrections. Use up to 100,000 individuals and parallel computing. It is possible to carry out orbit correction iteratively. Use up to 10 iterations.

Key observations:
1. All corrected losses are significantly lower than initial losses
2. Hybrid methods (especially with more iterations) show progressively better correction
3. Run 9 achieves the lowest corrected loss (3.156e-6)
4. Error bars show consistent performance across samples

The plot demonstrates how the hybrid SVD-NN approach, particularly with iterative refinement, progressively reduces residual orbit errors beyond what's achievable with pure SVD correction.
